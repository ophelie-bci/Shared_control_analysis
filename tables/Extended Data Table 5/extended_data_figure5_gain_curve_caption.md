# Extended Data Figure 2 | Group-specific gain curves and baseline-performance coverage

Each point is one target in one session. The x-axis shows baseline BCI-only success and the y-axis shows shared-control gain, defined as shared-control success minus BCI-only success; pp denotes percentage points. Quadratic fits were estimated from the same target x session observations with session-clustered standard errors; shaded bands show 95% confidence intervals derived from the session-clustered covariance matrix. Fit lines and confidence bands are drawn only over the observed baseline-performance range for the corresponding monkey or monkey x task dataset, while all scatter panels retain common 0-100% x-axis limits. Panel a shows separate fits by monkey. Panel b shows separate fits for each monkey x task dataset. Panel c shows the number of observations in each baseline-performance bin.

Source data: 255 target x session observations from 51 sessions.
